## Publication GitHub Pages — dossier /pouvoir

Fichiers à copier tels quels dans `DavidAuthentique/emilienaturelle`, sous le dossier `/pouvoir` (racine du sous-site), en remplaçant les fichiers existants :

- `index.html` — page d'accueil (landing page)
- `404.html` — page d'erreur personnalisée (GitHub Pages la sert automatiquement pour ce sous-dossier)
- `politique-de-confidentialite.html`
- `conditions-d-utilisation.html`

Chaque fichier est autonome (HTML/CSS/JS inline, images embarquées) — aucune dépendance externe à copier.

### Étapes
1. Dans le dépôt, place ces 4 fichiers dans `/pouvoir/`.
2. Vérifie que GitHub Pages est activé (Settings → Pages) sur la branche `main`.
3. Mets à jour les liens internes du footer/nav si l'URL finale diffère de `/pouvoir/politique-de-confidentialite.html` et `/pouvoir/conditions-d-utilisation.html`.
4. Commit + push.
